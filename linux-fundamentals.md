# Linux Fundamentals - Writeup

## Objective
Learn basic Linux commands and navigation.

## Tools Used
- Linux terminal

## Steps Taken
- Used `pwd` to find current directory
- Used `ls` to list files
- Used `cd` to navigate directories
- Used `cat` to read files

## Key Takeaways
- Linux command line is essential in cybersecurity
- Navigation and file handling are basic but critical skills
